# d20 入口 Prototype 计划

这是一个 throwaway UI prototype，保存在 [`prototype/d20-ui`](https://github.com/K4F7/entry2mysite/tree/prototype/d20-ui) 分支，用于回答“背景、骰子样式、投掷体验和桌面布局是否成立”。

## 目标

在桌面端验证入口界面的视觉和交互是否成立：背景、骰子样式、投掷节奏、拖拽旋转和整体布局。

## 范围

- Vite + TypeScript + Three.js
- 1440×900 主设计画布；保证 1280×720 至 1920×1080 可用
- 全屏静态斜向 `sein31` 重复纹样
- 中央、约占视口短边 35%–40% 的风格化低多边形 d20
- 可读的 1–20 数字
- 首次进入自动程序化投掷一次
- 点击/触摸投掷；鼠标拖拽旋转
- 可投掷状态使用克制的边缘呼吸光
- 停稳后朝向镜头、轻微靠近并短暂高亮最终数字
- 本地开发热重载

## 明确不做

- 移动端适配
- 声音和背景音乐
- 完整物理引擎、抓取甩掷
- 导航栏、页脚、标题和说明面板
- 文章、路由、主题持久化和正式结果池
- 复杂待机、悬停、视差或背景动画

## 验收标准

1. 用户打开页面即可看到自动投掷示范，并理解骰子是入口核心。
2. 点击能稳定触发投掷，动画有明显开始、滚动和停稳阶段。
3. 拖拽能旋转骰子，松手后不会出现失控跳转或布局溢出。
4. 停稳后的数字清晰可辨，结果主要通过骰面和短暂高亮表达。
5. 呼吸光能区分“可投掷”和“正在交互”两种状态，但不遮挡数字。
6. 在目标桌面尺寸范围内，骰子始终居中且背景纹样不抢夺焦点。
7. 颜色、材质和光效经过实际 prototype 截图/录屏后再定案。
