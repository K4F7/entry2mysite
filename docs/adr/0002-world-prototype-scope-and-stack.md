# ADR 0002：World 原型范围、渲染栈与资产

## 状态

已接受

## 决策

第一版保留固定 Portal，并实现一张固定大小、按 Asia/Shanghai 每日 Seed 生成的外围方格地图。地图必须保持道路连通和出生点安全；暂不接入真实项目、文章、事件或彩蛋内容。

World 使用普通六面骰子移动，点数直接对应前进格数。骰子固定在屏幕底部中央；主角可点击，显示返回 Portal 出生点的上下文按钮。镜头采用固定斜视角，支持拖拽平移、滚轮或双指缩放，并在移动时跟随主角。

实现继续使用 Three.js、TypeScript 与 Vite。Three.js 负责 3D 沙盘，DOM Overlay 负责骰子和上下文 UI；地图生成、移动规则和渲染对象保持分层。第一版使用 KayKit 低多边形资产作为正式视觉素材来源，先选用小型资产包验证组合与加载表现。

开发体验同样属于第一版基础约束：保留 Vite HMR，并通过统一注入边界为地图 Seed、地图生成、骰子结果和移动状态提供 dev-only mock。开发模式支持固定 Seed、固定点数、即时移动、状态重置和开发控制面板；真实逻辑变更时必须同步更新对应 mock。mock 和开发参数不得进入生产运行路径。

## 背景与取舍

现有仓库已经是 Three.js d20 原型，复用它可以直接验证低多边形 3D 沙盘和交互。Phaser、Canvas/SVG 和完整游戏引擎与 Diorama 目标不匹配；React Three Fiber 与 Babylon.js 在当前范围内增加的抽象和迁移成本高于收益。KayKit 能快速提供一致的低多边形建筑与环境资产，但正式使用前必须核对具体资产包的授权条件，并控制首屏加载量。
