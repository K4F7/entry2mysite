# ADR 0003：Portal 是固定起始地图区域

状态：已接受；修订 ADR 0002 对 Portal 的模糊描述。

用户确认 Portal 指地图中固定生成的起始区域及其中的常用入口。首次镜头靠近该区域，向外拖拽或缩小视野进入外围探索；不以脱离地图的卡片、侧栏或顶栏取代 Portal。

地图使用 24×24 方格。中央起始区域及建筑/装饰固定，外围由北京时间每日 seed 生成。常用入口的 DOM 标签锚定世界坐标，不要求主角抵达才可点击；原型中的真实网址暂不绑定。

骰子只在 World 探索状态出现。返回必须先点击主角，再点击返回气泡；点击画布只操作视野。岔路口等待用户选择，额度用完停止。

原型默认一段旅程使用进入时的地图，不在午夜强制替换正在行走的地图。下一次加载或开发面板重建使用当日 seed。此边界避免中途删除角色脚下道路。

开发通过同一个 Runtime 接口注入 seed、投掷、即时移动、相机跟随和地图生成。HMR 保存内存中的 seed/角色位置，取消当前动画并清理帧循环、事件、面板和 GPU 资源。生产构建不引入 dev 模块，URL mock 参数仅在开发模式生效。

原型分支保留 throwaway 标识，运行时验证完成不意味着用户已经选定入口标签美术变体。
