要求：
- 中文温馨克制 UI，基于第二轮 tokens；三个真实不同 Portal 布局 A 居中入口卡片、B 左侧入口栏、C 横向紧凑入口条。每个都有 Dev / Writing / Games / Lab / About 五个常用入口，样稿中按钮打开标注“入口占位”的本地面板，不伪造网址。
