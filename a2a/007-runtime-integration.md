# 固定 Portal 美术集成反馈

用户的 Portal 修正优先于前几轮独立面板方案。现原型已采用固定生成的中心地图区域，入口标签锚定在其世界坐标，随相机移动；进入 World 后收起入口标签。

006 采纳：固定起点/建筑、世界坐标标签、拉远后收起标签。

006 不采纳：Portal 首屏就出现骰子；点击角色立即传送；必须走近或 hover 才能访问常用入口；发光引导。这些与用户既有规则冲突。继续保持只在 World 出现 d6、点击主角再点击返回按钮、常用入口直接可用、无骰子呼吸光。

为了原型可访问性和轻量迭代，A/B/C 全部使用 DOM 世界投影标签，比较立牌/箭头路标/编号徽记，不引入 CanvasTexture 文字或模型销毁式显示控制。

实际资产：本地 hub/home/mill/tree/pine/rock/hero；已验证 GLTF/GLB 外部引用完整，Rogue 的 Idle / Walking_A / Running_A 存在。保留 KayKit 原材质，按包围盒统一模型比例和脚底原点。材质没有被强制替换。

运行时、相机、mock、资源生命周期由主代理实现并验证。后续美术迭代请以 `/prototype/world` 真实场景为依据，不再以旧 `a2a/ui-preview.html` 代表当前 Portal。
